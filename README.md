# Open Chair Advisory Landing Page

A modern, responsive landing page for Open Chair Advisory, professional advisory services built on clean design principles and streamlined user experience.

## Overview

This is the official landing page for Alex Williamson and Open Chair Advisory. The site showcases advisory services, work history, and provides a way for potential clients to connect and learn more about the advisory offerings.

## Features

- **Responsive Design**: Mobile-first approach with fluid typography and layout using Tailwind CSS
- **Modern Stack**: Built with vanilla HTML, CSS, and JavaScript for optimal performance
- **Accessibility**: Clean semantic HTML structure with proper heading hierarchy
- **Performance**: Optimized font loading and minimal external dependencies
- **Smooth Navigation**: Sticky navigation bar with smooth scroll behavior

## Technologies

- HTML5
- CSS3 (Tailwind CSS via CDN)
- JavaScript
- Google Fonts (Inter, DM Serif Display)

## Getting Started

### Prerequisites

- A modern web browser
- Basic web server (for local development)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/smallball300/Open-Chair-Advisory-Landing-Page.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Open-Chair-Advisory-Landing-Page
   ```

3. Open `index.html` in your browser or serve it locally:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Python 2
   python -m SimpleHTTPServer 8000
   
   # Using Node.js
   npx http-server
   ```

## Development

### Customization

To customize the landing page:

1. **Edit Content**: Update the HTML text directly in `OCA_landing_page.html`
2. **Styling**: Modify inline styles or add custom CSS in the `<style>` tag
3. **Colors**: Adjust Tailwind CSS classes or modify custom CSS variables

### Design System

- **Primary Font**: Inter (body text)
- **Display Font**: DM Serif Display (headings)
- **Color Palette**: Slate-based with neutral tones
- **Spacing**: Consistent 28px horizontal padding, 80px vertical sections

## Deployment

This is a static site and can be deployed to any web hosting service:

- GitHub Pages
- Vercel
- Netlify
- Traditional web hosting (upload HTML file)

### GitHub Pages Deployment

1. Ensure the repository is public
2. Go to repository Settings → Pages
3. Select main branch as source
4. Site will be available at: `https://smallball300.github.io/Open-Chair-Advisory-Landing-Page/`
